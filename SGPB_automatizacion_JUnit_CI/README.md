# Base de automatización del SGPB

Este paquete contiene una prueba JUnit 5 para el caso crítico CP-U01 (cálculo de multa) y el workflow de GitHub Actions propuesto en la entrega de la Unidad 3.

## Ejecución local

```bash
mvn test
```

## Integración

Copiar estos archivos al repositorio real del SGPB y adaptar el paquete/clase a la implementación del módulo. Luego hacer push para comprobar el workflow en GitHub Actions.
